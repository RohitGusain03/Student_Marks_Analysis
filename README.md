# Student Marks Analysis using NumPy

A beginner-friendly data analysis project built using Python and NumPy.

## Project Overview

This project analyzes student marks across multiple subjects using NumPy arrays.

## Features

- Store student marks using NumPy arrays
- Calculate total marks
- Calculate student averages
- Find the top-performing student
- Calculate subject averages
- Find highest and lowest marks
- Filter high-performing students
- Calculate basic statistics

## Technologies

- Python
- NumPy
- Jupyter Notebook

## Concepts Used

- NumPy arrays
- Array shape
- `np.sum()`
- `np.mean()`
- `np.max()`
- `np.min()`
- `np.argmax()`
- `np.median()`
- `np.std()`
- Boolean indexing
- `axis`
